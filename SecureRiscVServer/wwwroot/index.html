Această aplicație permite transmiterea securizată a instrucțiunilor RISC-V din browser către client.

Despre proiect

Acest proiect demonstrează un sistem sigur de comunicare pentru trimiterea de programe RISC-V către dispozitive client. Utilizează autentificare bazată pe token pentru a asigura securitatea transmisiei.
